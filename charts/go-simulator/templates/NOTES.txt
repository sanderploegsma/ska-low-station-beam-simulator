go-simulator (station_id={{ .Values.simulator.stationId }}, substation_id={{ .Values.simulator.substationId }}) has been installed as release {{ .Release.Name }}.

Reminder: this chart deploys ONE station pod per release. To simulate
another station, install a separate release with different
simulator.stationId/substationId/destIp/destPort values, e.g.:

  helm install {{ .Release.Name }}-2 {{ .Chart.Name }} --set simulator.stationId=2

The gRPC control plane (StartScan/StopScan/GetStatus/PushDelayUpdate) is
exposed via a {{ .Values.service.type }} Service on port {{ .Values.service.port }}.

{{- if eq .Values.service.type "LoadBalancer" }}

It may take a few minutes for the LoadBalancer's external IP to be
assigned. Check its status with:

  kubectl get svc --namespace {{ .Release.Namespace }} {{ include "go-simulator.fullname" . }} -w

Once assigned:

  export SIMULATOR_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "go-simulator.fullname" . }} -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
  grpcurl -plaintext $SIMULATOR_IP:{{ .Values.service.port }} list
{{- else if eq .Values.service.type "ClusterIP" }}

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "go-simulator.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
{{- else if eq .Values.service.type "NodePort" }}

  export NODE_PORT=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "go-simulator.fullname" . }} -o jsonpath='{.spec.ports[0].nodePort}')
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath='{.items[0].status.addresses[0].address}')
  grpcurl -plaintext $NODE_IP:$NODE_PORT list
{{- end }}

This pod also opens an OUTBOUND UDP connection to {{ .Values.simulator.destIp }}:{{ .Values.simulator.destPort }} (SPEAD heaps to CBF) — there is no Service for that side, since it's a connection this pod initiates itself, not one that needs exposing.
